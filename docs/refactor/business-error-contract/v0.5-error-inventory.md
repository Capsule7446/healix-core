# v0.5 Error Inventory and v0.6 Migration Matrix

This is the authoritative Core migration inventory for the v0.6 business-error contract. It distinguishes public business failures from private implementation causes. Each listed public producer must migrate to a registered `fault.Code`; private internal errors may remain ordinary Go errors only when they do not cross a Core public boundary.

## Shared fault contract

| v0.5 symbol/value | Producer | v0.6 replacement | Notes |
|---|---|---|---|
| no unified error contract | all Core contexts | `domain/fault.Error`, `Kind`, `Code`, `Param`, `Violation` | Safe message only; cause stays private except through `Unwrap`. |
| arbitrary error text checks | callers/tests | `fault.IsCode`, `fault.CodeOf`, `fault.KindOf` | Message is not a programmatic contract. |

## Execution context

| v0.5 symbol/value | Producer | v0.6 code family | Persistent/semantic responsibility |
|---|---|---|---|
| `node.ErrorKind`, `ClassifiedError` | `domain/node` | `EXECUTION_*` | New observations persist Kind + Code. Host maps historical v0.5 values during data migration; Core does not dual-read host storage. |
| `ErrElementNotFound` | `domain/node` | `EXECUTION_ELEMENT_NOT_FOUND` | Not-found retry/healing semantics remain unchanged. |
| context cancellation/deadline classifications | `domain/node` | `EXECUTION_OPERATION_CANCELED`, `EXECUTION_OPERATION_TIMEOUT` | Preserve `errors.Is` for context causes. |
| transient driver failure | `domain/node` | `EXECUTION_TRANSIENT_DRIVER` | Retryable `UNAVAILABLE` only. |
| unknown node operation failure | `domain/node` | `EXECUTION_OPERATION_FAILED` | Safe `INTERNAL`; never expose the driver cause. |
| `ErrUnsealedPlan` | `domain/execution` | `EXECUTION_PLAN_UNSEALED` | Failed precondition. |
| status-transition sentinels | `domain/execution` | `EXECUTION_*_STATUS_TRANSITION_INVALID` | Status facts remain normal domain state, not fault kinds. |
| `ErrStaleWorkerFence`, `StaleWorkerFenceError` | `domain/execution` | `EXECUTION_WORKER_FENCE_STALE` | Conflict/fence behavior must retain `errors.Is` semantics. |
| engine identity/authority/configuration sentinels | `application/engine` | `EXECUTION_*` | Application wraps cause with a fixed safe message. |
| execution step revision/commit/configuration sentinels | `application/execution` | `EXECUTION_*` | Includes command replay, stale revision, and adapter contract classifications. |
| scheduling create/run/queue/claim/reorder/abort sentinels and typed conflicts | `application/scheduling` | `EXECUTION_*` | Command identity, revision/CAS, state, queue scope, retryable signal, and adapter contract behavior are preserved. |

## Automation context

| v0.5 symbol/value | Producer | v0.6 code family | Persistent/semantic responsibility |
|---|---|---|---|
| `ValidationIssue.Code string` and joined validation messages | `domain/automation` | `AUTOMATION_*` | Top-level invalid-argument fault contains ordered typed violations with safe logical field paths. |
| `ErrFolderNotFound` | `domain/automation` | `AUTOMATION_FOLDER_NOT_FOUND` | No resource metadata beyond registered safe parameters. |
| revision and lifecycle sentinels | `domain/automation` | `AUTOMATION_*` | Revision zero/overflow, deleted aggregate, and version overflow receive registered codes. |
| repository revision/configuration sentinels and `RevisionConflictError` | `application/automation` | `AUTOMATION_*` | Preserve optimistic concurrency semantics without public string parsing. |
| heal review conflicts/contracts | `application/automation` | `AUTOMATION_*` | Candidate/base/review state remains governed by existing use cases. |
| sampling publication conflicts/contracts | `application/automation` | `SAMPLING_*` | Command payload and mapping must not enter a public message/parameter. |

## Other domain contexts

| Context | Migration rule |
|---|---|
| `domain/evidence` | Convert only public business validation, identity, and revision failures to `EVIDENCE_*`; terminal evidence remains a result/fact. |
| `domain/sampling` | Convert public lifecycle/publication boundary failures to `SAMPLING_*`; retain draft/session state semantics. |
| `domain/fingerprint` | Convert public input/parsing failures to `FINGERPRINT_*`; never include fingerprint source or selectors in safe detail. |
| `domain/interpolation` | Convert public namespace/syntax/missing-property failures to `INTERPOLATION_*`; never disclose parameter/environment values. |

## Required removal at v0.6 boundary

- No v0.5 exported sentinel or typed public error remains as a compatibility wrapper.
- No caller decides business behavior from `Error()` text or a legacy `ErrorKind` value.
- No public fault uses generic metadata maps, transport types/tags, locale data, stack traces, request IDs, or raw causes.
- Unknown ordinary errors stay ordinary within Core and must be converted by the Host boundary to a fixed safe `INTERNAL` response.
